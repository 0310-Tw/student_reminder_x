# Complete Push Notification Setup Guide for Flutter Apps
# Generic Step-by-Step Implementation Guide for Beginners

===============================================================================
OVERVIEW
===============================================================================

This guide provides a complete, generic implementation of push notifications 
for Flutter applications using Firebase Cloud Messaging (FCM). It covers both
local notifications (when app is open) and remote push notifications (when 
app is closed or in background).

Target Audience: Beginners to intermediate Flutter developers
Technologies: Flutter, Firebase, FCM, Cloud Functions

===============================================================================
PREREQUISITE SETUP
===============================================================================

### REQUIREMENTS (VERIFY BEFORE STARTING)

**1. Development Environment:**
```bash
# Verify Flutter is installed and working
flutter doctor

# Should show checkmarks for Flutter, Android toolchain, and IDE
```

**2. Node.js (for Firebase CLI):**
```bash
# Check Node.js version (should be 16+ for Firebase Functions)
node --version

# If not installed, download from: https://nodejs.org/
```

**3. Java (for Android development):**
```bash
# Check Java version (should be Java 11+)
java --version

# Required for Android builds with Firebase
```

**4. Firebase Account:**
- Google account with access to Firebase Console
- Credit card for Firebase Blaze plan (required for Cloud Functions)
- Note: Blaze plan has generous free tier, you likely won't be charged

**5. Platform-Specific Requirements:**

**Android:**
- Android Studio installed
- Android SDK and build tools
- USB debugging enabled on test device OR Android emulator

**iOS (if targeting iOS):**
- Xcode installed (macOS only)
- iOS Simulator or physical iOS device
- Apple Developer account (free tier sufficient for testing)

### FIREBASE PROJECT SETUP (DETAILED STEPS)

**Step 1: Create Firebase Project**
1. Go to https://console.firebase.google.com/
2. Click "Create a project" or "Add project"
3. Enter project name (e.g., "my-notification-app")
4. Enable/disable Google Analytics (optional but recommended)
5. Click "Create project" and wait for setup to complete

**Step 2: Enable Required Services**
1. In Firebase Console, go to "Authentication" → "Get started" → Enable
2. Go to "Firestore Database" → "Create database" → Start in test mode
3. Go to "Functions" → "Get started" → Upgrade to Blaze plan (required for Cloud Functions)
4. Go to "Cloud Messaging" → Already enabled by default

**Step 3: Add Your App to Firebase**
1. Click "Add app" → Select platform (Android/iOS)
2. **Android Setup:**
   - Package name: `com.yourcompany.yourapp` (must match your app)
   - App nickname: Your app name
   - SHA-1 certificate: Get from `keytool -list -v -keystore ~/.android/debug.keystore` (Linux/Mac) or `keytool -list -v -keystore %USERPROFILE%\.android\debug.keystore` (Windows)
   - Download `google-services.json`
3. **iOS Setup:**
   - Bundle ID: `com.yourcompany.yourapp` (must match your app)
   - App nickname: Your app name  
   - Download `GoogleService-Info.plist`

**Step 4: Download Configuration Files**
- `google-services.json` for Android
- `GoogleService-Info.plist` for iOS
- **CRITICAL:** These files contain your project's API keys and configuration

2. Name it `ic_stat_notification.png`

2. Upload your app icon or choose from clipart
3. Ensure it outputs as white icon with transparent background
4. Download and extract to `android/app/src/main/res/`

### 3.5 CRITICAL: Add google-services.json

1. Download `google-services.json` from Firebase Console
2. Place it in `android/app/google-services.json`
3. **This file is REQUIRED** - notifications will not work without it

### 3.6 Get SHA-1 Fingerprint (REQUIRED for Android)

**Why needed:** Firebase uses SHA-1 to verify your app's identity.

**Get SHA-1 fingerprint:**

**Windows:**
```bash
cd android
./gradlew signingReport

# Or using keytool directly:
keytool -list -v -alias androiddebugkey -keystore %USERPROFILE%\.android\debug.keystore
# Password: android
```

**macOS/Linux:**
```bash
cd android
./gradlew signingReport

# Or using keytool directly:
keytool -list -v -alias androiddebugkey -keystore ~/.android/debug.keystore
# Password: android
```

**Add SHA-1 to Firebase:**
1. Copy the SHA-1 fingerprint from the output
2. Go to Firebase Console → Project Settings → Your Android App
3. Click "Add fingerprint"
4. Paste the SHA-1 fingerprint
5. Click "Save"

**Note:** You'll need to add both debug and release SHA-1 fingerprints for production apps.

### 5.1 Create lib/src/services/notification_service.dart

```dart
import 'dart:convert';
import 'package:http/http.dart' as http;
import 'package:firebase_messaging/firebase_messaging.dart';
import 'package:flutter_local_notifications/flutter_local_notifications.dart';
import 'package:timezone/timezone.dart' as tz;
import 'package:timezone/data/latest.dart' as tz;

class NotificationService {
  // REPLACE with your Firebase project URL after deploying functions
  static const String _baseUrl = "https://YOUR_REGION-YOUR_PROJECT_ID.cloudfunctions.net";

  static NotificationService? _instance;
  static NotificationService get instance => _instance ??= NotificationService._();
  NotificationService._();

  // Local notifications plugin for foreground display
  static final FlutterLocalNotificationsPlugin _localNotifications =
      FlutterLocalNotificationsPlugin();

  static FirebaseMessaging? _messaging;
  static bool _initialized = false;

  /// STEP 1: Initialize the notification service
  static Future<void> initialize() async {
    if (_initialized) return;

    // Initialize timezone data for scheduled notifications
    tz.initializeTimeZones();

    _messaging = FirebaseMessaging.instance;

    // Request permissions
    await _messaging!.requestPermission(
      alert: true,
      badge: true,
      sound: true,
      provisional: false,
    );

    // Initialize local notifications for foreground display
    const androidSettings = AndroidInitializationSettings('@mipmap/ic_launcher');
    const iosSettings = DarwinInitializationSettings(
      requestAlertPermission: true,
      requestBadgePermission: true,
      requestSoundPermission: true,
    );

    const initSettings = InitializationSettings(
      android: androidSettings,
      iOS: iosSettings,
    );

    await _localNotifications.initialize(
      initSettings,
      onDidReceiveNotificationResponse: _onNotificationTapped,
    );

    // Create notification channel for Android
    const androidChannel = AndroidNotificationChannel(
      'default_channel',
      'Default Notifications',
      description: 'Default notification channel for your app',
      importance: Importance.high,
    );

    await _localNotifications
        .resolvePlatformSpecificImplementation<AndroidFlutterLocalNotificationsPlugin>()
        ?.createNotificationChannel(androidChannel);

    // Handle foreground messages
    FirebaseMessaging.onMessage.listen((RemoteMessage message) {
      print('Received foreground notification: ${message.notification?.title}');
      _showForegroundNotification(message);
    });

    // Handle notification taps when app is in background/terminated
    FirebaseMessaging.onMessageOpenedApp.listen((RemoteMessage message) {
      print('Notification tapped: ${message.notification?.title}');
      _handleNotificationTap(message);
    });

    _initialized = true;
  }

  /// STEP 2: Show notification when app is in foreground
  static Future<void> _showForegroundNotification(RemoteMessage message) async {
    const androidDetails = AndroidNotificationDetails(
      'default_channel',
      'Default Notifications',
      channelDescription: 'Default notification channel for your app',
      importance: Importance.high,
      priority: Priority.high,
      showWhen: true,
      enableVibration: true,
      playSound: true,
    );

    const iosDetails = DarwinNotificationDetails(
      presentAlert: true,
      presentBadge: true,
      presentSound: true,
    );

    const notificationDetails = NotificationDetails(
      android: androidDetails,
      iOS: iosDetails,
    );

    await _localNotifications.show(
      DateTime.now().millisecondsSinceEpoch ~/ 1000,
      message.notification?.title ?? 'Notification',
      message.notification?.body ?? 'You have a new message',
      notificationDetails,
      payload: message.data.toString(),
    );
  }

  /// STEP 3: Handle notification tap actions
  static void _onNotificationTapped(NotificationResponse response) {
    print('Notification tapped with payload: ${response.payload}');
    _handleNotificationTap(null, payload: response.payload);
  }

  static void _handleNotificationTap(RemoteMessage? message, {String? payload}) {
    // Implement your navigation logic here
    print('Handle notification tap - implement navigation');
  }

  /// STEP 4: Get FCM token for current user
  static Future<String?> getToken() async {
    if (_messaging == null) await initialize();
    return await _messaging!.getToken();
  }

  /// STEP 5: Subscribe to token refresh
  static void onTokenRefresh(Function(String) callback) {
    if (_messaging == null) return;
    _messaging!.onTokenRefresh.listen(callback);
  }

  /// STEP 6: Send push notification using Cloud Functions
  static Future<bool> sendPushNotification({
    required String deviceToken,
    required String title,
    required String body,
    String? type,
  }) async {
    final url = Uri.parse("$_baseUrl/sendFCMNotification");

    try {
      final response = await http.post(
        url,
        headers: {"Content-Type": "application/json"},
        body: jsonEncode({
          "token": deviceToken,
          "title": title,
          "body": body,
          "type": type ?? "general",
        }),
      );

      if (response.statusCode == 200) {
        print("Notification sent successfully: ${response.body}");
        return true;
      } else {
        print("Failed to send notification: ${response.statusCode} - ${response.body}");
        return false;
      }
    } catch (e) {
      print("Error sending push notification: $e");
      return false;
    }
  }

  /// STEP 7: Subscribe to topics
  static Future<void> subscribeToTopic(String topic) async {
    try {
      await FirebaseMessaging.instance.subscribeToTopic(topic);
      print("Subscribed to topic: $topic");
    } catch (e) {
      print("Error subscribing to topic $topic: $e");
    }
  }

  /// STEP 8: Send test notification
  static Future<bool> sendTestNotification() async {
    final token = await getToken();
    if (token == null) return false;

    return await sendPushNotification(
      deviceToken: token,
      title: 'Test Notification',
      body: 'This is a test notification!',
      type: 'test',
    );
  }
}
```

```javascript
const {onRequest} = require("firebase-functions/v2/https");
const admin = require('firebase-admin');

// Initialize Firebase Admin SDK
admin.initializeApp();

// Cloud Function to send FCM notifications
exports.sendFCMNotification = onRequest(async (request, response) => {
  try {
    const { token, title, body, type } = request.body;
    
    // Validate required fields
    if (!token || !title || !body) {
      response.status(400).send({ 
        error: 'Missing required fields: token, title, body' 
      });
      return;
    }

    // Construct the FCM payload
    const payload = {
      token: token,
      notification: {
        title: title,
        body: body,
      },
      data: {
        type: type || 'general',
        timestamp: Date.now().toString(),
      },
      // Android-specific options
      android: {
        priority: 'high',
        notification: {
          channelId: 'default_channel',
          priority: 'high',
          defaultSound: true,
          defaultVibrateTimings: true,
        },
      },
      // iOS-specific options
      apns: {
        payload: {
          aps: {
            alert: {
              title: title,
              body: body,
            },
            sound: 'default',
            badge: 1,
            'content-available': 1,
          },
        },
        headers: {
          'apns-priority': '10',
        },
      },
    };

    // Send the message
    const messageId = await admin.messaging().send(payload);
    console.log('Successfully sent message:', messageId);

    response.send({ 
      success: true, 
      messageId: messageId 
    });
    
  } catch (error) {
    console.error('Error sending FCM message:', error);
    response.status(500).send({ 
      error: error.message 
    });
  }
});

// Cloud Function to send notifications to topics
exports.sendTopicNotification = onRequest(async (request, response) => {
  try {
    const { topic, title, body, type } = request.body;
    
    if (!topic || !title || !body) {
      response.status(400).send({ 
        error: 'Missing required fields: topic, title, body' 
      });
      return;
    }

    const payload = {
      topic: topic,
      notification: {
        title: title,
        body: body,
      },
      data: {
        type: type || 'general',
        timestamp: Date.now().toString(),
      },
    };

    const messageId = await admin.messaging().send(payload);
    console.log('Successfully sent topic message:', messageId);

    response.send({ 
      success: true, 
      messageId: messageId 
    });
    
  } catch (error) {
    console.error('Error sending topic message:', error);
    response.status(500).send({ 
      error: error.message 
    });
  }
});
```

```dart
import 'package:firebase_core/firebase_core.dart';
import 'package:firebase_messaging/firebase_messaging.dart';
import 'package:flutter/material.dart';
import 'package:your_app/firebase_options.dart';  // IMPORTANT: Replace 'your_app' with your actual package name

// Background message handler for FCM
Future<void> firebaseMessagingBackgroundHandler(RemoteMessage message) async {
  await Firebase.initializeApp(options: DefaultFirebaseOptions.currentPlatform);
  print("Handling a background message: ${message.messageId}");
}

Future<void> initFirebase() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Firebase.initializeApp(
    options: DefaultFirebaseOptions.currentPlatform,
  );
}

Future<void> initNotifications() async {
  // Set up background message handler
  FirebaseMessaging.onBackgroundMessage(firebaseMessagingBackgroundHandler);

  // Initialize FCM and get token
  FirebaseMessaging messaging = FirebaseMessaging.instance;

  // Request permission
  NotificationSettings settings = await messaging.requestPermission(
    alert: true,
    badge: true,
    sound: true,
    provisional: false,
  );

  if (settings.authorizationStatus == AuthorizationStatus.authorized) {
    print("Notification permissions granted");
    
    // Get the token
    String? token = await messaging.getToken();
    print("FCM Token: $token");
    // IMPORTANT: Save this token to your database for sending notifications
    
  } else {
    print("Notification permissions denied");
  }
}
```

```dart
  String? _fcmToken;

  @override
  void initState() {
    super.initState();
    _initializeNotifications();
  }

  Future<void> _initializeNotifications() async {
    try {
      // CRITICAL: Initialize notification service
      await NotificationService.initialize();
      
      // Get FCM token and display it
      final token = await NotificationService.getToken();
      setState(() {
        _fcmToken = token;
      });
      print('FCM Token: $token');
      
      // Subscribe to default topics
      await NotificationService.subscribeToTopic('general');
      
      // Listen for token refresh
      NotificationService.onTokenRefresh((newToken) {
        setState(() {
          _fcmToken = newToken;
        });
        print('Token refreshed: $newToken');
      });
    } catch (e) {
      print('Error initializing notifications: $e');
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Text('Push Notifications Demo'),
```

### 8.1 User-to-User Notifications

```dart
// In your user service or messaging service
class MessagingService {
  static Future<void> sendNotificationToUser({
    required String targetUserId,
    required String title,
    required String body,
    String? type,
  }) async {
    try {
      // Get target user's FCM token from Firestore
      final userDoc = await FirebaseFirestore.instance
          .collection('users')
          .doc(targetUserId)
          .get();
      
      final userData = userDoc.data();
      final fcmToken = userData?['fcmToken'] as String?;
      
      if (fcmToken != null) {
        await NotificationService.sendPushNotification(
          deviceToken: fcmToken,
          title: title,
          body: body,
          type: type,
        );
      }
    } catch (e) {
      print('Error sending notification to user: $e');
    }
  }
}
```

```dart
// Send notifications to all users subscribed to a topic
class AdminNotificationService {
  static Future<void> broadcastToAllUsers({
    required String title,
    required String body,
  }) async {
    try {
      final response = await http.post(
        Uri.parse("${NotificationService._baseUrl}/sendTopicNotification"),
        headers: {"Content-Type": "application/json"},
        body: jsonEncode({
          "topic": "all_users",
          "title": title,
          "body": body,
          "type": "broadcast",
        }),
      );
      
      if (response.statusCode == 200) {
        print("Broadcast notification sent successfully");
      }
    } catch (e) {
      print("Error sending broadcast notification: $e");
    }
  }
}
```

TROUBLESHOOTING GUIDE - CRITICAL FIXES
===============================================================================

### COMMON ISSUES AND SOLUTIONS

**1. "MissingPluginException: No implementation found for method"**
- SOLUTION: Run `flutter clean && flutter pub get`
- SOLUTION: Restart your IDE and run `flutter run` again

**2. "FirebaseException: Failed to get token"**
- SOLUTION: Check `google-services.json` is in `android/app/`
- SOLUTION: Check `GoogleService-Info.plist` is in `ios/Runner/`
- SOLUTION: Verify internet connection

**3. "Notifications not appearing on Android"**
- SOLUTION: Check notification permissions in Settings > Apps > Your App > Notifications
- SOLUTION: Disable battery optimization for your app
- SOLUTION: Ensure `ic_stat_notification.png` exists in drawable folder

**4. "Cloud Functions returning 404"**
- SOLUTION: Verify functions are deployed: `firebase functions:list`
- SOLUTION: Check function URL in NotificationService matches deployed URL
- SOLUTION: Re-deploy functions: `firebase deploy --only functions`

**5. "FCM Token is null"**
- SOLUTION: Add google-services.json and GoogleService-Info.plist
- SOLUTION: Run `flutterfire configure` again
- SOLUTION: Check Firebase project has FCM enabled

**6. "Build failed - missing dependencies"**
- SOLUTION: Add all required dependencies to pubspec.yaml
- SOLUTION: Ensure minimum SDK version is 21 (Android)
- SOLUTION: Add `id("com.google.gms.google-services")` to android/app/build.gradle.kts

**7. "Scheduled notifications not working"**
- SOLUTION: Add `timezone` dependency to pubspec.yaml
- SOLUTION: Initialize timezone in NotificationService
- SOLUTION: Grant schedule exact alarm permission (Android 12+)

**8. "iOS notifications not working"**
- SOLUTION: Add GoogleService-Info.plist to Xcode project
- SOLUTION: Enable Push Notifications capability in Xcode
- SOLUTION: Configure APNs key in Firebase Console

### REQUIRED PERMISSIONS (Android 13+)

Add to AndroidManifest.xml if missing:
```xml
<uses-permission android:name="android.permission.POST_NOTIFICATIONS"/>
<uses-permission android:name="android.permission.SCHEDULE_EXACT_ALARM"/>
```

### COMMON "GOTCHAS" THAT BREAK SETUP

❌ **Package name mismatch:** Android app ID ≠ Firebase package name
❌ **Missing google-services.json:** File not in android/app/ directory  
❌ **Wrong notification icon:** Not white PNG or wrong location
❌ **Outdated dependencies:** Using old Firebase versions
❌ **Missing SHA-1:** Debug fingerprint not added to Firebase
❌ **Wrong build.gradle:** Editing root instead of app-level build.gradle
❌ **Case sensitivity:** File paths and package names are case-sensitive
❌ **Network issues:** Firewall blocking Firebase services
❌ **Permissions:** Notification permissions denied on device
