# Firebase Cloud Functions Setup Documentation
# Student Reminder App - Functions Implementation Guide

===============================================================================
OVERVIEW
===============================================================================

This document explains how Firebase Cloud Functions were set up and integrated 
into the Student Reminder Flutter application for handling server-side operations,
push notifications, and admin functionalities.

===============================================================================
WHAT WAS DONE TO SET UP THE FUNCTIONS FOLDER
===============================================================================

1. FIREBASE FUNCTIONS INITIALIZATION
   Command executed: firebase init functions
   
   This command:
   - Created the functions/ directory structure
   - Set up Node.js environment with package.json
   - Configured ESLint for code quality
   - Generated initial template files

2. DIRECTORY STRUCTURE CREATED
   functions/
   ├── .eslintrc.js          # ESLint configuration for code quality
   ├── .gitignore           # Git ignore rules for functions directory
   ├── package.json         # Node.js dependencies and npm scripts
   ├── package-lock.json    # Locked dependency versions for consistency
   ├── index.js            # Main functions entry point (exported functions)
   ├── sendNotification.js  # Custom notification utility functions
   ├── test-notifications.js # Testing utilities for notification functions
   ├── node_modules/       # Node.js packages and dependencies
   └── src/                # Additional source files for organization

3. KEY DEPENDENCIES INSTALLED
   Core Dependencies (package.json):
   - firebase-admin: ^12.6.0    # Server-side Firebase SDK for admin operations
   - firebase-functions: ^6.0.1  # Cloud Functions runtime and utilities
   
   Development Dependencies:
   - eslint: ^8.15.0                    # JavaScript linting tool
   - eslint-config-google: ^0.14.0     # Google's ESLint configuration
   - firebase-functions-test: ^3.1.0   # Testing framework for functions

4. FIREBASE CONFIGURATION UPDATED
   Updated firebase.json to include functions configuration:
   
   {
     "functions": [
       {
         "source": "functions",
         "codebase": "default",
         "ignore": [
           "node_modules",
           ".git", 
           "firebase-debug.log",
           "firebase-debug.*.log",
           "*.local"
         ]
       }
     ]
   }

===============================================================================
FUNCTIONS IMPLEMENTATION DETAILS
===============================================================================

A. MAIN FUNCTIONS FILE (index.js)
   
   1. Hello World Function
      Purpose: Basic test function to verify deployment
      Endpoint: /helloWorld
      Method: GET/POST
      Response: "Hello from Firebase!"
   
   2. FCM Notification Function
      Purpose: Send Firebase Cloud Messaging notifications
      Endpoint: /sendFCMNotification
      Method: POST
      Parameters:
        - token: Device FCM token (required)
        - title: Notification title (required)
        - body: Notification message (required)
        - type: Notification type (optional, default: 'admin_action')
      
      Features:
        - Enhanced foreground notification support
        - Android-specific notification channels
        - iOS APNS configuration
        - High priority delivery
        - Error handling and logging

B. NOTIFICATION UTILITIES (sendNotification.js)
   
   1. sendNotificationToToken()
      Purpose: Send notification to specific device token
      Parameters: token, title, body, data
      Use case: Individual user notifications
   
   2. sendNotificationToTopic()
      Purpose: Send notification to topic subscribers
      Parameters: topic, title, body, data
      Use case: Broadcast notifications to groups

C. TESTING UTILITIES (test-notifications.js)
   Purpose: Local testing and debugging of notification functions

===============================================================================
INTEGRATION WITH FLUTTER APP
===============================================================================

The Flutter app integrates with these functions via HTTP requests:

Example HTTP Call from Flutter:
```dart
import 'package:http/http.dart' as http;
import 'dart:convert';

Future<void> sendNotification(String token, String title, String body) async {
  final response = await http.post(
    Uri.parse('https://us-central1-student-reminder-xx-16738.cloudfunctions.net/sendFCMNotification'),
    headers: {'Content-Type': 'application/json'},
    body: json.encode({
      'token': token,
      'title': title,
      'body': body,
      'type': 'admin_action'
    }),
  );
  
  if (response.statusCode == 200) {
    print('Notification sent successfully');
  } else {
    print('Failed to send notification: ${response.body}');
  }
}
```
